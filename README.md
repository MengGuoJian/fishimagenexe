# FishImagen EXE 下载

此仓库**只发布 Windows 二进制包，不包含项目源码、号池、个人配置或账号数据**。

## 安装

1. 下载仓库中的 `ImageStudio_v0.1.0_binary.zip`。
2. 解压后保留完整的 `ImageStudio/` 文件夹（`ImageStudio.exe` 和 `_internal/` 必须在一起）。
3. 双击 `ImageStudio.exe`，本机打开软件无需登录。生成图片和配置仅保存在你的电脑。

> 运营者可在软件目录自行配置 `config.json` 与号池数据库；不要将含密钥的配置、数据库或个人图片上传至此仓库。
